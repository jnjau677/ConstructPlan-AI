## 2026-03-05 - Route Code Splitting and Bundle Size Optimization
**Learning:** Codebases utilizing heavy visual libraries like `recharts` (Dashboard.tsx) and large text processing libraries like `react-markdown` (AiDesignAssistant.tsx) can suffer from massive initial chunk sizes (960.15kB) if loaded synchronously. Since these architectural features reside in separate main navigation sections, they can be lazy-loaded completely independently.
**Action:** Replace direct imports with `React.lazy()` dynamic imports, and wrap tab rendering logic in a unified `Suspense` fallback. By placing the `Suspense` boundary inside Framer Motion's `<AnimatePresence>` animated wrapper child `<motion.div>`, transition transitions are smoothly executed without premature exit/mount glitches. This reduced the main bundle size by ~64.8% (960.15kB down to 337.54kB).
