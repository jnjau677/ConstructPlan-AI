## 2026-03-06 - Reducing Initial Bundle Size with Lazy Loading Sub-Modules
**Learning:** Statically importing all components for tabbed/sub-module architectures causes the initial bundle to swell significantly (960.15 kB), especially when containing heavy libraries like recharts, date-fns, and react-markdown. By code-splitting each module using React.lazy combined with Suspense, we defer loading of these dependencies entirely, saving over 622 kB (~64.8%) on the main initial JS asset and making page loads incredibly snappy. When using Framer Motion's AnimatePresence with mode="wait", the Suspense boundary must reside inside the motion.div child to preserve exit/enter transitions correctly.
**Action:** Always identify sub-module paths, tabs, or routes that are not immediately visible upon initial load, and utilize dynamic imports via React.lazy with clear Suspense fallbacks. Place Suspense inside any animated motion wrappers to prevent layout disruptions or premature unmounts.
