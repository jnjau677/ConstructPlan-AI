## 2026-03-01 - Dynamic Code Splitting on Large Recharts and Markdown Assets
**Learning:** In a highly interactive dashboard with massive modular elements like Recharts, custom canvas elements, and heavy third-party parsing dependencies (e.g. react-markdown), putting all components in a single bundle can bloat the main entry point to nearly 1MB. Code splitting these into separate chunks not only decreases initial load size by ~65%, but also allows browser threads to download and compile non-essential tab resources only on-demand.
**Action:** Always identify components loaded conditionally (like behind routes or state-driven tab switchers) and apply React.lazy and Suspense code splitting. Wrapping Suspense inside Framer Motion's AnimatePresence child ensures animations are fully preserved without breaking enter/exit states.
