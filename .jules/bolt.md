## 2025-05-15 - [Tab-level Code Splitting]
**Learning:** Implementation of tab-level code splitting using `React.lazy` and `Suspense` reduced the initial JavaScript bundle size by approximately 65% (from ~957kB to 338kB), which significantly improves initial load performance for complex dashboards.
**Action:** Prioritize code splitting for non-critical path components in modular applications to maintain a lean entry bundle.
