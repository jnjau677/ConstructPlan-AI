## 2026-08-10 - Motion AnimatePresence & Suspense Integration
**Learning:** Placing Suspense boundaries outside of `AnimatePresence` or outside of a `motion.div` during route/tab lazy loading breaks the exit animations because the component is unmounted instantly rather than waiting for the exit transition to complete. Placing `<Suspense>` inside the `<motion.div>` preserves the seamless tab sliding transition while still lazily loading chunks. Additionally, memoizing random element properties prevents layout shifts when adjacent items are toggled.
**Action:** Always wrap the lazy components in `<Suspense>` *inside* the `<motion.div>` when using Framer Motion’s exit animations, and use `useMemo` for any UI generated with non-deterministic generators (like `Math.random()`) to keep layout stable across re-renders.
