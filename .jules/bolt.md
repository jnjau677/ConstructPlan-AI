## 2026-08-06 - Dynamic Code Splitting on Heavy Third-Party Libraries
**Learning:** In a single-page React app (Vite), importing heavy third-party dependencies like Recharts, date-fns, and react-markdown across multiple side-by-side modules (tabs) results in a massively bloated initial JS bundle (~960 kB). Standard lazy loading via React.lazy with AnimatePresence can break enter/exit transitions if the Suspense boundary is misplaced.
**Action:** Always wrap dynamically loaded tab/view components in a React.Suspense boundary nested *inside* the AnimatePresence's motion.div element. This preserves exit transitions perfectly while isolating module chunks (splitting off Recharts and react-markdown into separate assets), resulting in ~65% reduction in the initial page weight.
