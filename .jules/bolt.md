## 2026-08-03 - Lazy Loading Submodules in Single Page Apps
**Learning:** In a single page app where all heavy submodules (Dashboard with complex charting, SiteAnalysis, TakeoffEstimator, AiDesignAssistant, etc.) are imported eagerly, the initial JS bundle size is extremely bloated (approx. 960kB), leading to delayed initial rendering and poor performance on low-bandwidth/constrained devices. Dynamic code splitting via `React.lazy` and `Suspense` allows loading components on demand, dramatically reducing the main entry chunk size.
**Action:** Always inspect the main entry chunk size after production builds. If any heavy module or route/tab component is not immediately required on the initial page load, split it into a separate chunk using dynamic `import()` and `React.lazy`. Place `Suspense` inside `motion.div` to ensure exit and enter animations under Framer Motion's `AnimatePresence` work correctly during lazy module transition.
