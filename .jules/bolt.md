## 2026-07-25 - Code Splitting & Module-Level Lazy Loading
**Learning:** For application-scale dashboards with heavy-weight modules (like Rechards, react-markdown, and custom Canvas/LiDAR rendering utilities), bundle-bloat can heavily impact Time-to-Interactive (TTI) and initial page-load performance. Code splitting at the React layout level can offload these dependencies and dynamic components. Furthermore, placing Suspense boundaries correctly inside Framer Motion's AnimatePresence child containers (like motion.div) guarantees fluid page transitions and prevents UI stutter when swapping chunks.
**Action:** Always identify secondary layout tabs and split them dynamically using React.lazy and custom Suspense fallback UI. Ensure the loading aesthetic matches the core layout.
