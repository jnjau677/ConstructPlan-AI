## 2026-08-08 - Lazy Loading Sub-Modules with Framer Motion AnimatePresence
**Learning:** In projects that have heavily visual components with heavy package dependencies (like `recharts`, `date-fns`, or `react-markdown`), initial bundle size can balloon. Dynamic routing or lazy loading components with React `lazy` is incredibly effective but requires careful orchestration when combined with Framer Motion's `AnimatePresence`. To preserve layout exit animations, the `Suspense` boundary should be positioned inside the `motion.div` representing the animating page rather than surrounding it.
**Action:** Always lazy load heavy sub-modules at tab or page level, place the `Suspense` boundary inside the `motion.div` wrapper, and design a custom, themed fallback component matching the application aesthetic to maintain a high-quality user experience.
